## 1. Executive Summary & Architectural Overview

Phase 10 constructs the mathematical core of TransferIn's on-device culling engine: a **Zero-Allocation Luminance Histogram & Exposure Classifier** capable of evaluating captured preview frames in **$<1.8\text{ms}$ with $0\text{ B}$ JVM heap allocation in the hot loop**.

In tethered studio and commercial shoots (15–30 fps bursts across 40MP–100MP cameras), flash misfires (producing pitch-black frames) or strobe misconfigurations (producing blown highlights) can clutter client folders and waste cellular data and Google Drive cloud storage. By evaluating the lightweight Tier 1 embedded JPEG preview slice before pulling multi-megabyte RAW files, TransferIn provides instant on-device feedback and smart auto-culling.

### Core Capabilities Delivered:
1. **Fixed-Point ITU-R BT.601 Integer Bit-Shift Math (`CULL-01`):** Fast luminance calculation:
   $$Y = (77 \cdot R + 150 \cdot G + 29 \cdot B) \gg 8$$
   Operating on downsampled pixel buffers ($256 \times 170$) with pre-allocated reusable `IntArray(256)` bin buffers to guarantee $0\text{ B}$ JVM heap allocations per frame.
2. **Deterministic Flash Misfire Classification (`CULL-02`):** Multi-feature classification classifying frames as `UNDEREXPOSED_CRITICAL` when:
   - Sensor Black Floor Density ($Y \le 3$) exceeds $98\%$.
   - Mean Luminance $\bar{Y} < 15.0$.
   - Shannon Histogram Entropy $H = -\sum p_i \log_2(p_i) < 1.0$.
   This multi-feature rule prevents false-positive culling on intentional low-key studio portraits or silhouette compositions ($H \ge 3.0$).
3. **Deterministic Highlight Blowout Classification (`CULL-03`):** Dual-condition classification classifying frames as `OVEREXPOSED_BLOWN` when:
   - Highlight Saturation ($Y \ge 248$) exceeds $20\%$.
   - Mean Luminance $\bar{Y} > 230.0$.
   Distinguishes small specular catchlights and jewelry reflections from catastrophic whole-frame blowout.
4. **Picture Profile & MakerNote Dynamic Calibration (`CULL-04`):** Picture profile parsing (e.g. Fujifilm *Acros*, *Velvia*, *Monochrome+R*, Canon *Monochrome*, Sony *B&W*) applying dynamic clipping offsets so artistic high-contrast B&W film simulations are preserved as `OPTIMAL`.
5. **Microbenchmark & Synthetic Test Suite (`QUAL-01`):** Comprehensive JUnit4 unit tests and microbenchmark validation verifying $<1.8\text{ms}$ execution time, $0\text{ B}$ heap delta, and $100\%$ classification accuracy across synthetic edge-case fixtures (pure black, pure white, linear gradient, low-key portrait, high-key cyclorama).

## 4. Work Breakdown Structure & Task List

### Task 1: Fixed-Point ITU-R BT.601 Integer Luminance Math & Reusable 256-Bin Histogram (`CULL-01`)

- **Target Files:**
  - `app/src/main/java/com/rvmeur/transferin/data/analysis/LuminanceHistogram.kt`
  - `app/src/main/java/com/rvmeur/transferin/data/analysis/ExposureMetrics.kt`
  - `app/src/main/java/com/rvmeur/transferin/data/analysis/ExposureAnalyzer.kt`
- **Implementation Details:**
  1. Create `LuminanceHistogram` holding a fixed `IntArray(256)` bins buffer, with zero-allocation utility functions (`reset()`, `record(luma: Int)`, `copyInto(destination: IntArray)`).
  2. Implement fixed-point integer bit-shift luminance calculation:
     $$\text{luma} = (77 \cdot R + 150 \cdot G + 29 \cdot B) \gg 8$$
     where $R, G, B \in [0, 255]$.
  3. Implement pixel scanning logic over packed RGB_8888, RGB_565, and raw byte arrays without intermediary object allocations.
  4. Ensure thread-safe zero-allocation scratch buffering using `ThreadLocal<ExposureScratchBuffer>` or instance-level reusable buffer pools.
  5. Implement $O(256)$ Shannon histogram entropy calculation:
     $$H = -\sum_{i=0}^{255} p_i \log_2(p_i) = \log_2(N) - \frac{1}{N} \sum_{i=0}^{255} \text{count}_i \log_2(\text{count}_i)$$
     avoiding object allocation and using fast logarithm math.
- **Test-Driven Verification:**
  - `ExposureAnalyzerMathTest`:
    - Verify luminance calculation matches standard BT.601 values for pure Red (77/256 ≈ 0.299), Green (150/256 ≈ 0.587), and Blue (29/256 ≈ 0.114).
    - Verify Shannon entropy returns $0.0$ for single-bin monochrome spike and $\approx 8.0$ for flat uniform distribution.
    - Verify 10,000 consecutive analysis iterations execute with $0\text{ B}$ garbage collection allocation delta.

### Task 2: Multi-Feature Exposure Classification Engine (`CULL-02`, `CULL-03`)

- **Target Files:**
  - `app/src/main/java/com/rvmeur/transferin/data/analysis/ExposureClassification.kt`
  - `app/src/main/java/com/rvmeur/transferin/data/analysis/ExposureAnalysisResult.kt`
  - `app/src/main/java/com/rvmeur/transferin/data/analysis/ExposureAnalyzer.kt`
- **Implementation Details:**
  1. Define `ExposureClassification` enum:
     - `OPTIMAL`: Well-balanced or acceptable exposure distribution.
     - `UNDEREXPOSED_CRITICAL`: Severe flash misfire or total underexposure.
     - `OVEREXPOSED_BLOWN`: Severe strobe burnout or unrecoverable highlight clipping.
  2. Define `ExposureAnalysisResult` data class containing:
     - `classification: ExposureClassification`
     - `meanLuminance: Float` (0.0 .. 255.0)
     - `blackFloorDensity: Float` (% of pixels with $Y \le 3$)
     - `shadowClippingPercent: Float` (% of pixels with $Y \le 15$)
     - `highlightSaturationPercent: Float` (% of pixels with $Y \ge 248$)
     - `shannonEntropy: Float` (bits of entropy, 0.0 .. 8.0)
     - `histogramBins: IntArray` (256 bins)
  3. Implement deterministic decision logic in `ExposureAnalyzer.evaluate()`:
     - **Flash Misfire Rule (`UNDEREXPOSED_CRITICAL`):**
       `blackFloorDensity >= 0.98f && meanLuminance < 15.0f && shannonEntropy < 1.0f`
     - **Highlight Blowout Rule (`OVEREXPOSED_BLOWN`):**
       `highlightSaturationPercent >= 0.20f && meanLuminance > 230.0f`
     - **Default:** `OPTIMAL`
  4. Ensure low-key studio scenes (e.g. 85% black background with subject midtones producing $H \ge 3.0$) and high-key wedding scenes (70% in $Y \in [200, 245]$) evaluate strictly as `OPTIMAL`.
- **Test-Driven Verification:**
  - `ExposureClassificationTest`:
    - Synthetic pitch-black frame (100% $Y=0$) $\to$ `UNDEREXPOSED_CRITICAL`.
    - Synthetic low-key studio frame (85% $Y=2$, 15% $Y=128$, $H=3.2$) $\to$ `OPTIMAL`.
    - Synthetic blown white frame (100% $Y=255$) $\to$ `OVEREXPOSED_BLOWN`.
    - Synthetic high-key bridal frame (75% $Y=220$, 10% $Y=255$, $\bar{Y}=210$) $\to$ `OPTIMAL`.
    - Synthetic linear gradient ($Y=0..255$) $\to$ `OPTIMAL`.
