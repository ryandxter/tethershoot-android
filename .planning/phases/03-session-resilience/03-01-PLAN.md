3. Add pooled operation wrapper:
```kotlin
private suspend fun <T> withPooledSession(
    block: suspend (ChannelSftp) -> Result<T>
): Result<T> {
    val pool = sessionPool ?: return Result.failure(
        IllegalStateException("Session pool not initialized. Call initializePool() first.")
    )
    
    val session = pool.acquireSession()
    return try {
        block(session.channel).also {
            session.lastUsedAt = System.currentTimeMillis()
        }
    } catch (e: Exception) {
        pool.markUnhealthy(session)
        Result.failure(e)
    } finally {
        pool.releaseSession(session)
    }
}
```

4. Update `testConnection()` to use pooled session:
```kotlin
override suspend fun testConnection(/* same params */): Result<Unit> = 
    withPooledSession { Result.success(Unit) }
```

5. Keep `withSftp()` as fallback for direct connections (for backward compatibility during migration). In later plans, migrate all methods to `withPooledSession`.

Per RESEARCH.md: Each channel operation acquires→uses→releases the session. Never share channels across operations.
