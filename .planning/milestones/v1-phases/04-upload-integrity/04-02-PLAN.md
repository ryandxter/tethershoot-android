       - Add `data class PartFileInfo(val name: String, val fullPath: String, val size: Long, val modifiedAt: Long)`
       - Add `suspend fun stalePartFileCleanup(host: String, port: Int, username: String, password: String, remoteDirectory: String)`:
         - Call sftpClient.listPartFiles()

         - For each stale file, call sftpClient.deletePartFile()

         - Call cleanupPartFile() to delete any existing stale .part
         - Call transferQueueDao.requeue() to reset progress for clean retry

    4. **Add extension method to TwoPhaseUploadHandler**:
