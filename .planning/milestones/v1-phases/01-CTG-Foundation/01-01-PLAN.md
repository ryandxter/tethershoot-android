# Phase 1 Plan 01: CTG Foundation - Tracer (End-to-End CTG Parsing)

## Objective

**As a** photographer shooting tethered
**I want to** have TransferIn automatically detect new photos by parsing Canon CTG database files
**So that** the app can accurately track which files have been transferred vs. which are new

### Purpose
Build the foundational CTG (Canon Thumbnail Group) SQLite database parsing layer. Lead with a production-quality end-to-end slice that wires CTG file discovery through SQLite parsing to an immutable snapshot model. This tracer proves the architecture works before expanding.

### Output
Three new domain layer classes that parse Canon CTG files, extract media entries, and create immutable snapshots.

**Structure:**
```kotlin
data class CtgMediaEntry(
    val handle: Int,              // MTP object handle
    val filename: String,         // Original filename
    val size: Long,               // File size in bytes
    val modifiedTime: Long,       // Last modified timestamp (millis)
    val capturedTime: Long?,      // Capture timestamp (if available)
    val formatCode: Int           // MTP format code (JPEG/RAW/VIDEO)
) {
    // Immutable fingerprint: uniquely identifies this media across sessions
    val fingerprint: String
        get() = "$handle|$filename|$size"
    
    // Display-friendly size
    val displaySize: String
        get() = when {
            size >= 1_073_741_824 -> String.format("%.1f GB", size / 1_073_741_824.0)
            size >= 1_048_576 -> String.format("%.1f MB", size / 1_048_576.0)
            size >= 1024 -> String.format("%.1f KB", size / 1024.0)
            else -> "$size B"
        }
    
    // Check if this is a photo (not folder/association)
    val isPhoto: Boolean
        get() = formatCode != 0x3000  // FORMAT_ASSOCIATION
}
```

**Design notes:**
- Fingerprint uses handle + filename + size (NOT just handle) to avoid collisions across camera sessions
- formatCode 0x3000 = MTP FORMAT_ASSOCIATION (folder), all others are media files
- Include init block to validate required fields are positive

**DO:**
- Make handle, filename, size required (non-nullable, validated)
- Make modifiedTime required
- Include `companion object` with empty factory for testability
- Document MTP format codes in kdoc

**DO NOT:**
- Do not add mutable state
- Do not add file I/O logic
- Do not reference Android context
</action>

Create an immutable snapshot of camera media state captured at a point in time.

**Package:** `com.rvmeur.transferin.domain.shoot`

**Structure:**
```kotlin
/**
 * Immutable snapshot of camera media state captured at session start.
 * 
 * Once created, cannot be modified. Create a new snapshot when state changes.
 * Used for comparing current camera state against baseline to detect new photos.
 */
data class CtgMediaSnapshot(
    val id: String,                           // UUID for this snapshot
    val capturedAt: Long,                     // Timestamp when snapshot was created
    val storageId: Int,                        // MTP storage ID
    val cameraId: String?,                    // Camera device identifier
    val mediaCount: Int,                       // Total number of media entries
    val entries: Map<String, CtgMediaEntry>, // fingerprint -> entry (sorted)
    val checksum: String                      // SHA-256 of sorted fingerprints for integrity
) {
    init {
        require(capturedAt > 0) { "capturedAt must be positive" }
        require(mediaCount >= 0) { "mediaCount cannot be negative" }
        require(mediaCount == entries.size) { "mediaCount must match entries size" }
    }
    
    /**
     * Check if a specific file is in this snapshot
     */
    fun contains(fingerprint: String): Boolean = fingerprint in entries
    
    /**
     * Get entry by fingerprint
     */
    fun get(fingerprint: String): CtgMediaEntry? = entries[fingerprint]
    
    /**
     * Get all entries as list
     */
    fun allEntries(): List<CtgMediaEntry> = entries.values.toList()
    
    /**
     * Get fingerprints sorted by filename for stable checksum
     */
    private fun sortedFingerprints(): List<String> = 
        entries.values.sortedBy { it.filename }.map { it.fingerprint }
    
    companion object {
        /**
         * Create snapshot from parsed CTG database
         */
        fun fromCtgDatabase(
            ctgDb: CtgDatabase,
            storageId: Int,
            cameraId: String?
        ): CtgMediaSnapshot {
            require(ctgDb.records.isNotEmpty()) { 
                "Use createEmpty() for cameras with no media" 
            }
            
            val entries = ctgDb.records.associate { record ->
                record.fingerprint to record
            }
            
            val checksum = generateChecksum(entries.keys.sorted())
            
            return CtgMediaSnapshot(
                id = UUID.randomUUID().toString(),
                capturedAt = System.currentTimeMillis(),
                storageId = storageId,
                cameraId = cameraId,
                mediaCount = entries.size,
                entries = entries,
                checksum = checksum
            )
        }
        
        /**
         * Create empty snapshot for cameras with no media
         */
        fun createEmpty(storageId: Int, cameraId: String?): CtgMediaSnapshot {
            return CtgMediaSnapshot(
                id = UUID.randomUUID().toString(),
                capturedAt = System.currentTimeMillis(),
                storageId = storageId,
                cameraId = cameraId,
                mediaCount = 0,
                entries = emptyMap(),
                checksum = generateChecksum(emptyList())
            )
        }
        
        private fun generateChecksum(sortedFingerprints: List<String>): String {
            val data = sortedFingerprints.joinToString("|")
            val digest = MessageDigest.getInstance("SHA-256")
            val hash = digest.digest(data.toByteArray(StandardCharsets.UTF_8))
            return hash.joinToString("") { "%02x".format(it) }
        }
    }
}
```

**Required imports:**
```kotlin

import java.security.MessageDigest
import java.util.UUID
```

**Design notes:**
- entries Map uses fingerprint as key for O(1) contains/get operations
- Checksum is SHA-256 of sorted fingerprints for integrity verification
- Factory methods ensure valid state at construction
- Empty snapshot uses createEmpty() factory, not constructor directly

**DO:**
- Use UUID.randomUUID() for snapshot ID
- Generate SHA-256 checksum for integrity
- Keep entries as immutable Map
- Add init block validation

**DO NOT:**
- Do not expose mutable collections
- Do not add methods that modify state
- Do not add Android-specific dependencies
</action>

## Threat Model

### Trust Boundaries

| Boundary | Description |
|-----------|-------------|
| MTP Device -> App | Untrusted input: CTG file downloaded from camera via MTP |
| SQLite Database -> App | Untrusted input: CTG file contents parsed by SQLiteDatabase |

### STRIDE Threat Register

| Threat ID | Category | Component | Severity | Disposition | Mitigation Plan |
|-----------|----------|-----------|----------|-------------|-----------------|
| T-CTG-01 | Denial | CTG file malformed | Medium | Mitigate | Try-catch in parseCtgFile; return null on error; log details |
| T-CTG-02 | Denial | CTG file very large | Medium | Mitigate | Process in streaming fashion; set reasonable limits |
| T-CTG-03 | Tampering | CTG schema varies | Low | Accept | Fallback query patterns; log schema for debugging |
| T-CTG-04 | Denial | MTP import fails | Medium | Mitigate | Verify file exists and size > 0 before SQLite open |
| T-CTG-SC | Supply Chain | No external dependencies | N/A | Accept | All parsing uses Android platform SQLite API |
