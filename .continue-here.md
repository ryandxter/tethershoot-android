<decisions_made>

3. **Confirmed-only cache eviction invariant:** Prevents data loss under any transit storage pressure.
4. **Adversarial USB packet fuzzing:** Guarantees zero crashes on malformed camera responses or abrupt cable pulls.

## Critical Anti-Patterns (do NOT repeat these)
- **Do NOT use fake MediaStore polling:** Always rely on camera event streams (`0x4002`/`0xC001` for Fuji, `0x9116` for Canon, SDIO for Sony, `0x90C1` for Nikon).
- **Do NOT bypass JNI IO Latches:** All native USB bulk/control transfers must pass through `SafeUsbTransportManager` to prevent native `libusbhost.so` `SIGSEGV` page faults.
- **Do NOT evict unconfirmed transit files:** Only `CONFIRMED_CLOUD` files can be purged from local storage.
